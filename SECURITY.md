# Security policy

Do not open a public issue for a suspected vulnerability or include secrets,
OAuth material, member data, or private conversation content in an issue.

Report security concerns privately to `hello@workwork.bot` with the subject
`Security report`. Include the affected plugin version, a concise impact
description, and safe reproduction steps. Do not include live credentials.

The plugin is instructions and connection metadata. Service-side security and
privacy information is available at <https://workwork.bot/privacy>.
